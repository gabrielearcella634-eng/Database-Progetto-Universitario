# Database Progetto Universitario — Formula 1

## Descrizione

Progetto universitario dedicato alla progettazione e alla gestione dei dati attraverso database relazionali e strumenti di analisi. Il progetto comprende script SQL, dati in formato CSV e un file Excel per lavorare sui dati relativi alla Formula 1.

L'obiettivo è organizzare le informazioni, gestire le relazioni tra i dati e supportare le attività di interrogazione ed elaborazione attraverso strumenti differenti.

## Tecnologie e strumenti

- **SQL** — definizione e interrogazione dei database.
- **Database relazionale** — organizzazione dei dati e gestione delle relazioni tra le entità.
- **CSV** — archiviazione e scambio dei dati tabulari.
- **Microsoft Excel** — consultazione ed elaborazione dei dati.

## Contenuto dei file

- **`CSV_Arcella_1129044.csv`** — file contenente dati in formato tabellare.
- **`database_ARCELLA_1129044.sql`** — script SQL relativo al database del progetto.
- **`dw_formula1_arcella_1129044.sql`** — script SQL relativo al data warehouse della Formula 1.
- **`excel_arcella_1129044.xlsx`** — cartella di lavoro Excel utilizzata nell'ambito del progetto.

## Obiettivi formativi

Il progetto permette di applicare concetti relativi a:

- Modellazione e organizzazione dei dati.
- Gestione di database relazionali.
- Utilizzo di SQL per la definizione e l'interrogazione dei dati.
- Integrazione tra dati strutturati e strumenti di analisi come Excel.
- Organizzazione dei dati per attività di consultazione ed elaborazione.

## Esecuzione

Per utilizzare gli script SQL, è necessario disporre di un DBMS compatibile con la sintassi utilizzata nel progetto.

1. Esaminare gli script SQL e verificare eventuali dipendenze tra le tabelle.
2. Preparare il database e importare i dati CSV secondo la procedura prevista.
3. Eseguire gli script nell'ordine corretto, utilizzando il DBMS compatibile.
4. Aprire il file Excel per consultare o elaborare i dati disponibili.

La procedura esatta dipende dal DBMS e dalla configurazione utilizzati durante lo sviluppo.
